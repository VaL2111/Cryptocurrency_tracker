# Cryptocurrency Tracker

**Cryptocurrency Tracker** — це вебзастосунок, розроблений як персональний 
кабінет для інвесторів та трейдерів. Він дозволяє користувачам в одному 
інтерфейсі відстежувати ринок криптоактивів, керувати власним списком 
обраних монет та переглядати актуальні новини.

**Доступ до всіх інструментів надається лише після автентифікації.**

## Основні можливості:
### Автентифікація та профіль:
* Реєстрація нових користувачів та вхід до системи (з використанням JWT).
* Можливість керувати власним профілем: оновлювати персональні дані, змінювати пароль або видаляти свій обліковий запис.

### Головна панель (Дашборд):
* Після входу користувач бачить швидкий огляд ринку.
* Відображення ключових активів (наприклад, Bitcoin та Ethereum), їхні мініграфіки та список монет з найбільшою капіталізацією.

### Персональний список відстеження (Watchlist):
* Основна функція, що дозволяє користувачам створювати власний список "обраних" монет.
* Користувач може додавати активи до свого списку та видаляти їх. Цей список зберігається в базі даних і прив'язаний до профілю.

### Деталізований перегляд активу:
* Можливість перейти на окрему сторінку конкретної монети.
* На сторінці відображається розширена інформація: іконка, символ, поточна ціна та зміни за 24 години.

### Стрічка новин:
* Окремий розділ, що агрегує та відображає останні новини зі світу криптовалют у вигляді карток з посиланням на першоджерело.

## Технологічний стек:

### Backend:
* **NestJS**
* **PostgreSQL** (з використанням Sequelize)
* **JWT** (для автентифікації та авторизації)
* **Swagger** (для документації REST API)


### Frontend:
* **React**
* **React Router** (для навігації)
* **Material UI (MUI)** (для компонентів інтерфейсу та темізації)
